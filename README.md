# 🚀 PesaJet Developer Reference & Demos

Welcome to the official developer reference repository for the **PesaJet** ecosystem.

This repository provides code samples, integration starter kits, and reference implementations for developers building on PesaJet's financial infrastructure across East Africa.

---

## 📦 Active Integration Guides

| Guide / Starter Kit                                    | Description                                                                                                                                                  | Status                |
| :----------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------- |
| **[Official SDKs (`sdks/`)](./sdks)**                  | Official client libraries for Node.js (`@pesajet/sdk`), Python (`pesajet` on PyPI), PHP, and Go.                                                             | 🟢 **Active Release** |
| **[Webhook Reference Server (`webhook/`)](./webhook)** | Complete reference server for receiving, handling, and cryptographically verifying PesaJet HMAC-SHA256 webhook notifications across MTN MoMo & Airtel Money. | 🟢 **Active Release** |

## 🌐 The PesaJet Ecosystem

Explore our platforms and product suites:

- 🏛️ **[PesaJet (pesajet.com)](https://pesajet.com)**: Main company portal and unified financial services infrastructure.
- 💳 **[PesaJet Payments (payments.pesajet.com)](https://payments.pesajet.com)**: Full-stack merchant payment gateway, mobile money collections, API credentials, and developer dashboard.
- 🎓 **[ShulePay (shulepay.pesajet.com)](https://shulepay.pesajet.com)**: Specialized digital tuition, fees collection, and institutional reconciliation platform for schools and universities.
